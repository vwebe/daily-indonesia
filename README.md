# Daily Indonesia

GitHub Pages/Jekyll blog for Indonesian daily news posts generated by the Google Sheets auto script.

## Site

- GitHub user: `vwebe`
- Repository: `daily-indonesia`
- Public URL: `https://vwebe.github.io/daily-indonesia/`

## Upload

Upload all files in this ZIP to the root of the `daily-indonesia` repository, then enable GitHub Pages:

- Settings → Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/root`

## Auto script config

Use these values in the Google Sheet `Config` sheet:

```text
PUBLISH_TARGET      github
GITHUB_ENABLED      1
GITHUB_OWNER        vwebe
GITHUB_REPO         daily-indonesia
GITHUB_BRANCH       main
GITHUB_POSTS_PATH   _posts
GITHUB_SITE_TYPE    jekyll
```

Do not commit API keys or GitHub tokens to this repository.
